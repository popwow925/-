# AI 陪玩伙伴 (AI Buddy) — Fabric 1.21.1

填入一个大模型 API Key，召唤一个玩家外观的伙伴。它能用中文跟你聊天，并按你说的话去行动：跟随、护卫、打怪、砍树挖矿、盖房子、给你东西。

作者：D0cK & Claude · MIT License

## 编译出 jar

需要 **JDK 21**。

**方法一：本地编译**
```bash
./gradlew build        # Windows: gradlew.bat build
```
产物在 `build/libs/aibuddy-1.0.0.jar`（不要用带 `-sources` 的那个）。

**方法二：GitHub 在线编译（不用装任何东西）**
1. 新建一个 GitHub 仓库，把整个文件夹传上去
2. 打开仓库的 **Actions** 页，等 `build` 跑完（约 3–5 分钟）
3. 点进那次运行，在底部 Artifacts 下载 `aibuddy-jar`

## 安装
1. 安装 Fabric Loader（1.21.1）
2. 把 `aibuddy-1.0.0.jar` 和 **Fabric API**（1.21.1 版）放进 `.minecraft/mods`

## 使用
1. 进入世界，按 **K** 打开设置界面：
   - 点「预设」循环切换 DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI / 本地 Ollama
   - 填 API Key，点「测试连接」，成功后「保存」
2. 输入 `/aibuddy summon` 召唤伙伴（进游戏时聊天栏也有可点的按钮）
3. 直接在聊天栏说话就行，比如：
   - 「跟着我」「在这等着」「过来」
   - 「帮我砍 10 个木头」「去挖点铁矿」
   - 「用圆石在这盖个 5x5 的小屋」
   - 「把木头都给我」「你背包里有啥」
   - 「打那只猪」「晚上保护我」
4. **右键伙伴**打开它的背包（27 格），可以放材料、工具、盔甲、食物进去；也可以直接把东西丢在它脚边让它捡

伙伴会自动：护卫你（攻击附近敌对生物）、穿最好的盔甲、拿最好的武器/工具、血少时吃东西、走太远时传送回你身边。

## 指令
| 指令 | 作用 |
|---|---|
| `/aibuddy summon` | 召唤 / 传送到身边 |
| `/aibuddy dismiss` | 解散（物品掉在原地） |
| `/aibuddy status` | 查看配置和伙伴状态 |
| `/aibuddy reset` | 清空对话记忆 |
| `/aibuddy key <key>` | 设置 API Key（服务器用） |
| `/aibuddy url <地址>` | 设置接口地址 |
| `/aibuddy model <模型>` | 设置模型名 |
| `/aibuddy name <名字>` | 改伙伴名字 |

配置文件：`.minecraft/config/aibuddy.json`。其中 `chatPrefix` 默认为空（你说的每句话都会发给伙伴），多人服可以改成 `"@"`，只有 `@` 开头的话才发给它；`autoChat` 控制天黑、低血量等事件时伙伴是否主动说话。

## 工作原理
- 大模型只负责**决策**：每次你说话（或发生事件），mod 把伙伴和你的状态（位置、血量、背包、附近生物、时间天气）整理成文字发过去，模型回一段 JSON：要说的话 + 动作列表。
- **执行**全在本地：走路寻路、战斗、挖掘进度、放方块都是每 tick 的游戏代码，所以不会因为网络延迟卡顿，也只在需要时才花 token。
- 接口是 OpenAI 兼容的 `/chat/completions`，几乎所有国内外服务商和本地 Ollama 都能用。

## 已知限制
- 伙伴是「玩家外观的生物」，不是真正的玩家：不会出现在 Tab 列表，不能用工作台合成、不会开箱子。
- 挖矿只在 20 格范围内找；矿藏在石头里时会朝它挖一条通道，但复杂地形可能卡住（卡住会换一块）。
- 不会挖箱子、熔炉、床等带方块实体的东西，也不会挖黑曜石以上硬度的方块。
- 跨维度不会自动跟随，到了新维度再 `/aibuddy summon` 一次即可（背包会一起带过来）。
- 专用服务器上，按 K 的设置只改你本地的配置；服务器要用 `/aibuddy key` 等指令（需要 OP）。
